# Ferrers rank-metric code bounds

A dependency-free GitHub Pages website for certified bounds on the dimension of
Ferrers-diagram rank-metric codes.

Open `index.html` locally, or publish the repository root using GitHub Pages.
The current catalog supports diagrams with at most 10 columns and height 10,
minimum rank distances from 1 through 10, and finite-field sizes
2, 3, 4, 5, 7, 8, 9, 11, and 13.

For each query, the site reports:

- the Etzion–Silberstein singleton-like upper bound;
- the strongest embedded rectangular MRD-code construction found by the
  catalog, extended by zero elsewhere in the diagram.

The displayed references identify the source of each bound or construction.
